# ⚖️ Oliveira & Associados — Site Institucional

> Projeto de site institucional para escritório de advocacia, desenvolvido como exercício prático de habilidades em HTML, CSS e JavaScript.

---

## 📋 Sobre o Projeto

Este projeto consiste em um site completo e responsivo para um escritório de advocacia fictício chamado **Oliveira & Associados Advogados**. O objetivo foi praticar e demonstrar habilidades de desenvolvimento front-end, criando uma página profissional e visualmente atraente do zero.

---

## 🚀 Funcionalidades

- **Navegação fixa** com scroll suave entre seções e menu responsivo para mobile
- **Seção Hero** com estatísticas, chamadas para ação e imagem de destaque
- **Seção Sobre** com diferenciais do escritório e imagem da equipe
- **Galeria** com grid de imagens do escritório
- **Áreas de Atuação** com 6 cards de serviços jurídicos
- **Casos de Sucesso** com destaque para conquistas relevantes
- **Benefícios** com numeração visual e descrições
- **Depoimentos** de clientes em cards com avaliação por estrelas
- **FAQ** com acordeão interativo (abrir/fechar perguntas)
- **Formulário de Contato** com informações completas do escritório
- **Footer** completo com links rápidos, redes sociais e copyright
- **Botão "Voltar ao Topo"** com aparição por scroll

---

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Uso |
|---|---|
| **HTML5** | Estrutura semântica e acessível da página |
| **CSS3** | Estilização, animações, Grid e Flexbox |
| **JavaScript** | Interatividade (menu mobile, FAQ, scroll) |
| **Font Awesome** | Ícones da interface |
| **Unsplash** | Imagens de alta qualidade (uso educacional) |

## 📱 Responsividade

O projeto foi desenvolvido com foco em responsividade, adaptando-se a diferentes tamanhos de tela:

- 📱 **Mobile** — até 768px
- 📟 **Tablet** — 768px a 1024px
- 🖥️ **Desktop** — acima de 1024px

## 🎯 Aprendizados

Durante o desenvolvimento deste projeto, foram praticados:

- Estruturação semântica com HTML5 (`<header>`, `<nav>`, `<section>`, `<footer>`)
- Layout moderno com **CSS Grid** e **Flexbox**
- Criação de componentes reutilizáveis via CSS
- Interatividade com **JavaScript puro** (sem frameworks)
- Uso de variáveis CSS para consistência visual
- Design responsivo com **media queries**
- Animações e transições CSS para UX refinada
